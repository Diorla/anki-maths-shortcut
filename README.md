# Math Shortcut Converter for Anki

This add-on replaces the shortcuts in `main.py` with their Unicode symbols as
you type in an Anki note field. A shortcut is converted when you type a
separator such as a space or comma; for example, typing `\alpha ` produces
`α `.

To install it on Windows, create a folder for the add-on under
`%APPDATA%\Anki2\addons21\` and copy `__init__.py` and `main.py` into that
folder. Restart Anki to load the add-on.
